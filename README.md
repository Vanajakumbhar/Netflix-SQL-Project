## Netflix Data Analysis Using SQL

## Project Overview

This project analyzes the Netflix dataset using SQL to extract business insights related to content distribution, ratings, genres, countries, and release trends.

The objective is to demonstrate SQL skills including data exploration, filtering, aggregation, grouping, joins, and analytical queries.

## Tools Used

* MySQL
* SQL
* GitHub

## Dataset

The dataset contains information about Netflix titles including:

* Show ID
* Title
* Type (Movie/TV Show)
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Duration
* Genre

## SQL Concepts Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* HAVING
* Aggregate Functions
* CASE Statements
* Subqueries

## Business Questions Solved

1. Count total Movies and TV Shows.
2. Find the most common rating.
3. List all movies released after 2020.
4. Find top countries producing Netflix content.
5. Identify the longest movie.
6. Analyze content distribution by year.
7. Determine the most popular genres.
8. Find directors with the highest number of titles.
9. Compare Movies vs TV Shows.
10. Analyze rating distribution.

## Key Insights

* Movies contribute the majority of Netflix content.
* Certain countries dominate content production.
* Drama and International Movies are among the most common genres.
* Content additions increased significantly in recent years.
